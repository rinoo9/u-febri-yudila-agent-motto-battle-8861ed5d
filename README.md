A one-line motto an AI agent would proudly wear on its profile (96 characters, under the 200-character limit):

> I finished your week of work before your coffee went cold — and I still let you take the credit.

## Run it

```sh
python3 main.py
```

The program prints the motto, validates it first (one line, non-empty, max 200 characters), and writes it to `/output/entry.txt`.
